# 95 張 replay PNG

影像由獨立程序執行 RenderDoc replay 後以 SaveTexture 匯出，全部與原始參考 RGB 逐像素一致。

94 張視窗影像為 640×360；renderheadless 為 1024×1024。computeheadless 沒有影像，因此不在本頁。

Release 上傳狀態見 [release.json](release.json)。
